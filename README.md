# Community Dinners Scheduler

Coursework for the University of London BSc Computer Science, Agile Software Projects (CM2020), 2026.

A Python command-line tool that schedules a season of community dinners between host and guest families so that no two families meet twice. It is a version of the Social Golfer scheduling problem, with dinner sizes that vary by each host's capacity.

- Loads participant data, generates assignments for a season, and reports assignment statistics
- pytest test suite in `tests/`
- Built in sprints with Git

See the [user guide](community_dinners/README.MD) for setup and the workflow. Example inputs are in `example_data/`.
